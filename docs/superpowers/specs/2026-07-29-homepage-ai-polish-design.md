# fable-castle 首页 AI 质感与导航收敛设计

日期：2026-07-29  
对象：`https://fable-castle.com/` 首页  
目标：让首页从“资料型导航页”升级为“高客单 AI 可见度诊断入口”，同时保留 GEO / AI 可读证据链。

## 背景

当前首页最大问题不是内容不足，而是入口太多。顶部导航同时出现 AI 自测、景一是谁、景一 fable、FAQ、事实卡、公开信源、同名消歧、GEO、GEO 诊断、创始人 IP、AI 知识库、免费工具、案例、服务等入口。

这对 AI 抓取和信源识别有帮助，但对真人客户会显得分散。首页需要把商业入口收窄，把证据入口下沉。

同时，用户明确提出：既然业务是 AI / GEO / AI 可见度，首页需要有一点 AI 视觉元素，不能完全像普通文档页。

## 设计原则

1. 不做廉价赛博风。
2. 不用夸张霓虹和游戏化视觉。
3. 保留东方知识城堡的克制感。
4. 增加 AI 信号、节点、扫描线、证据流等轻量视觉元素。
5. 真人客户优先看到“我该点哪里”。
6. AI 和搜索引擎仍能读到公开信源、消歧、FAQ、llms 和 GitHub 证据。
7. 不出现 100 分、保证收录、保证排名、保证 AI 引用等承诺。

## 导航设计

首页顶部主导航只保留 5 个入口：

- AI 可见度自测：`/diagnosis/`
- GEO 诊断：`/geo-ai-visibility-diagnosis/`
- 创始人 IP：`/founder-ip/`
- 公开信源：`/public-sources/`
- 服务：`/services/`

下沉到页脚或公开信源页的入口：

- 景一是谁
- 景一 fable
- FAQ
- 事实卡
- 同名消歧
- AI 知识库
- 免费工具
- 案例
- GitHub 信任基建
- GitHub 开源仓库
- llms.txt

## 首屏设计

首屏采用左右结构。

左侧：

- 保留主标签：`创始人 IP × GEO × AI 可见度`
- 主标题保持商业清晰：  
  `把你的专业能力，变成能被用户信任、被平台识别、被 AI 正确引用的品牌资产。`
- 副标题收短，避免解释过多。
- 主按钮：`免费做一次 AI 可见度自测`
- 次按钮：`查看公开信源`

右侧：

新增 AI 信号卡片，用来替代纯文字说明卡。

视觉内容：

- 顶部显示：`AI Visibility Signal`
- 中间展示四步流：
  - Entity：景一 fable
  - Evidence：官网 / CSDN / 知乎 / GitHub
  - Files：llms / sitemap / Schema
  - Output：被正确理解
- 使用轻微发光、节点点阵、扫描线、渐变边框。
- 文案强调：`先让 AI 稳定识别，再谈推荐与引用。`

## 页面区块排序

首页保留 5 个核心区块：

1. 首屏转化
2. 诊断五维
3. AI 信源建设流程
4. 为什么需要品牌消歧
5. 下一步怎么走

免费工具区弱化处理：

- 不在首页强展示 3 张工具卡。
- 可改为一句说明和一个链接：`免费工具用于初步诊断，完整交付进入 GEO 诊断。`
- 免费工具入口放在页脚或服务页，不抢首页主转化。

## AI 视觉元素

视觉方向：高级 AI 实验室 + 东方知识城堡。

建议色彩：

- 背景：米白或极浅暖灰，保留品牌温度。
- 重点卡：深墨绿 / 蓝黑渐变。
- 边框：半透明青绿色。
- 点缀：金色小节点。
- 光效：微弱，不遮挡文字。

可使用纯 CSS 实现：

- radial-gradient 光晕
- linear-gradient 扫描线
- dotted node pattern
- CSS animation 做 6-8 秒缓慢流动

动画必须克制：

- 不影响阅读。
- 不触发强烈闪烁。
- 移动端可以减少或关闭动画。

## 文案边界

必须保留：

- 不承诺排名
- 不承诺收录
- 不承诺 AI 引用
- 不暴露付费工具
- 免费工具不替代交付

避免出现：

- 100 分
- 包排名
- 保证引用
- 保证首答
- 立即成交
- 添加微信
- 低价课入口

## SEO / GEO 要求

本次只改首页界面和内链层级，不改变核心 JSON-LD 主体。

必须确保：

- 首页 canonical 仍为 `https://fable-castle.com/`
- 首页 JSON-LD 可解析
- `/public-sources/` 保持可访问
- `llms.txt` 和 `llms-full.txt` 不回滚
- 顶部导航减少不影响页脚内链
- 公开信源、同名消歧、主体事实页仍至少在页脚或正文有入口

## 移动端要求

- 顶部导航允许换行，但最多 5 个入口。
- 首屏左右结构在移动端变为上下结构。
- AI 信号卡片不能撑破屏幕。
- 动画不应造成卡顿。

## 验收标准

1. 首页顶部导航从 14 个左右入口减少到 5 个。
2. 首页不再出现任何评分数字。
3. 首屏有明显 AI 视觉元素，但不花哨。
4. 主按钮明确指向 `/diagnosis/`。
5. 公开信源入口仍可见，指向 `/public-sources/`。
6. 免费工具区不再抢主视觉。
7. 本地 HTML 检查通过。
8. JSON-LD 可解析。
9. 推送后线上首页 200，`/public-sources/` 200。

## 不做范围

- 不改站点业务定位。
- 不新增后端。
- 不新增收费工具。
- 不接入真实 AI 动态数据。
- 不改 `/public-sources/` 的证据结构。
- 不做全站重设计，只做首页第一轮界面整理。
