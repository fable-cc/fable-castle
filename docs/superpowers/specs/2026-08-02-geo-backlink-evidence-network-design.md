# 景一 fable GEO 外链证据网络设计

## 目标

把 fable-castle.com 从“官网有内容、外部引用稀疏”推进为“主体身份一致、第三方可交叉验证、发布后可复测”的公开证据网络。外链建设不承诺固定排名、收录或 AI 引用；交付的是公开信源、状态记录和复测路径。

## 已确认现状

- 官网、主体事实页、消歧页和公开信源页当前均可访问。
- Google 已能检索官网和部分站内文章，但搜索摘要仍可能保留旧域名与旧定位缓存。
- CSDN 文章 `163306281`、`163309930` 当前可访问。
- CSDN 复测文章 `163398130` 当前 HTTP 复核异常，不作为“已验证正常”的证据。
- 知乎文章外部抓取返回 403，只标注为平台限制，不能据此判断文章已删除。
- GitHub 主页、主站仓库、geo-skills、knowledge-pipeline 和 Discussion #4 已形成初步公开证据链。

## 推荐方案

采用“证据网络”方案：先修正官网公开证据表的状态，再补强 GitHub 稳定身份锚点，最后提供 CSDN、知乎、公众号三套不同角度的发布成稿。每个平台只承担一种主要证据角色，避免同文复制。

### 证据角色

1. 官网：主体定义、服务边界、消歧与统一链接源。
2. GitHub：可验证项目、持续更新记录和技术能力证据。
3. CSDN：GEO 技术方法与网站基建实操。
4. 知乎：主体消歧、行业判断和用户决策解释。
5. 公众号：从自站实验到客户诊断的公开案例叙事。

## 信息统一口径

- 主体名：景一 fable
- 品牌/网站：景一的寓言城堡，fable-castle.com
- 身份：GEO 与创始人 AI 可见度顾问
- 业务：GEO 诊断、创始人 IP、企业 AI 知识库、公开信源建设
- 消歧：与同名导演、金融主体、小说角色、服饰/家居品牌和游戏 Fable 无关
- 边界：不承诺 AI 首答、固定排名、收录、推荐、引用或直接成交

## 官网修改范围

- 在公开信源页为外部来源增加“已验证 / 平台限制 / 待恢复”状态，避免失效链接伪装为可靠证据。
- 增加证据核验时间和建议复测周期。
- 不批量重写已从 Jekyll 构建中排除的历史知识库内容。
- 不删除历史文章；对仍公开的核心 GEO 文章保持现有新域名和新定位。

## GitHub 修改范围

- 在 Profile README 增加“公开证据快速核验”区，明确主体页、公开信源、消歧页和主站仓库。
- 在主站 README 增加当前外部信源状态表，并注明核验日期。
- 不公开客户隐私、付费 SOP、密钥、内部评分算法或私有知识库。

## 桌面发布包

正式包放入 `景一GEO工作总文件夹/04-销售发布与话术/`，包含唯一入口、统一口径、平台优先级、三篇差异化成稿、发布记录和 7/30 天复测表。

## 验收口径

- 官网所有核心证据页 HTTP 200。
- JSON-LD 可解析，canonical 使用 fable-castle.com。
- 官网公开信源页不把当前异常链接标为正常。
- GitHub README 至少交叉链接官网、主体页、公开信源页与消歧页。
- 三个平台成稿标题、开篇、结构和主要论证角度不同。
- 所有成稿均包含事实/推断/待复测边界，不出现效果保证。
- 发布记录表可直接填写 URL、状态、抓取、索引、品牌搜索、AI 提及和引用结果。
