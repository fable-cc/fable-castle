整理结论

层级用途网站呈现方式
A 核心资产直接证明你的 GEO 与知识资产能力首页、llms.txt、服务页都可引用
B 支撑资产证明自动化和主体身份在本页解释，不抢主入口
C 实验资产可保留，但避免造成品牌分裂只作为补充，不做主卖点
D 噪音资产名称弱、说明弱、信任信号弱暂不放首页；后续重命名或归档
